# 源码构建与验证

本次发布目标为 Windows / UE 5.8.2。其他引擎版本未承诺兼容。源码和映射蓝图均可修改；不需要作者的 VRM 模型才能编译。

## 构建

安装与本机 UE 版本相配的 Visual Studio C++ 工具链和 Windows SDK。关闭编辑器后，在 C++ 项目中将插件放入 `Plugins/VRMFaceNodes`，生成 Visual Studio 项目，构建 **Development Editor / Win64**，成功后重开 UE。

也可在 PowerShell 中使用引擎自带 BuildPlugin（把路径换成自己的；输出文件夹必须与源码不同）：

```powershell
& 'E:/UE_5.8/Engine/Build/BatchFiles/RunUAT.bat' BuildPlugin '-Plugin=D:/Source/VRMFaceNodes/VRMFaceNodes.uplugin' '-Package=D:/Build/VRMFaceNodes' -TargetPlatforms=Win64
```

若启用了 Live Coding，不要在涉及 UCLASS/USTRUCT 的更新后直接热加载再导入模型。使用关编辑器、常规编译、重新打开的流程。

## 自动化测试

插件自带 `VRMFaceNodes.*` 测试，覆盖映射、手调基线、校准响应、镜像轴、延迟、配置管理和相机校正等。在 UE 的 Session Frontend → Automation 中搜索 `VRMFaceNodes`。

`ManualReferenceParity`、`ManualAnimationPipeline`、`ChinAndMasterAnimation` 需要作者项目测试资产。公开包不含这些资产，测试会记录跳过说明；它们不代表公开包完成了实机面捕或通用模型几何验证。其余可移植测试可在装有插件的空项目执行。

## 开源范围检查

- 必须保留 `Content/Presets/BP_ManualFacialRemap.uasset`，运行模块对它有硬引用。
- 不提交 Binaries、Intermediate、Saved、模型、录制或个人配置。
- 不提交 `Resources/VerifiedMouthProfile.json`。缺少该文件时，专用牙齿/下巴几何生成功能安全退出。
- 第三方通道表的版权声明在 `ThirdPartyNotices.md` 中。

发布构建和测试结果另见随交付包提供的验证记录；本页只说明复现方法，不将未执行的检查表述为已通过。
